# Shark FlexStyle images

The `/shark-flexstyle` landing page expects these three marketing graphics in this
folder. Upload them with these **exact** file names:

| File name | What it is |
|-----------|------------|
| `salon-blowout.jpg` | The **"Salon Blowout at Home"** before/after graphic (hero + OG image) |
| `transformation.jpg` | The **"10-Minute Hair Transformation"** lifestyle graphic |
| `why-switching.jpg` | The **"Why Women Are Switching"** old-routine-vs-FlexStyle graphic |

If a file is missing, the page automatically falls back to `placeholder.svg`, so the
layout never breaks. Once you add the real files with the names above, they appear
automatically — no code changes needed.

> Tip: keep them reasonably sized (square-ish, under ~500 KB) for fast loading.
